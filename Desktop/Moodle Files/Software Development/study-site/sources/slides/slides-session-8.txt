@pytest.mark.parametrize(
    ("minimum", "expected"),
    [
        (0.0, [("dining", 15.0)]),
        (10.0, [("dining", 10.0)]),
        (100.0, []),
    ],
)
def test_minimum_filters_small_amounts(
    minimum: float,
    expected: list[tuple[str, float]]
    ) -> None:
    expenses = [Expense("d", "m", "dining", 5.0), Expense("d", "m", "dining", 10.0)]
    assert total_by_category(expenses, "", minimum) == expected

===== [slides-session-8.pdf] page 11 =====
Choose edge cases on purpose
Ask
Example
Empty: nothing in?
total_by_category([], "", 0.0) == []
Zero: the boundary?
an amount exactly equal to minimum
Negative: nonsense?
a refund
Duplicate: twice?
our expenses.csv has six exact duplicates
Missing: not there?
a category nobody used
Do not test what feels likely. Test what could break.
For this reason, it is often said that tests also behave as documentation.

===== [slides-session-8.pdf] page 15 =====
Green: the smallest code that passes
def remove_duplicates(expenses: list[Expense]) -> list[Expense]:
    seen: set[Expense] = set()
    unique: list[Expense] = []
    for expense in expenses:
        if expense not in seen:
            seen.add(expense)
            unique.append(expense)
    return unique
Not elegant. Nobody asked for elegant yet. All green.

===== [slides-session-8.pdf] page 16 =====
Refactor: with the tests as a net
def remove_duplicates(expenses: list[Expense]) -> list[Expense]:
    return list(dict.fromkeys(expenses))
Dictionaries keep insertion order, and @dataclass(frozen=True) makes Expense
hashable. Session 6's frozen=True pays off here.
Run the tests: still green. That is what "refactoring" means.

Coverage is a map, not a score
uv add --dev pytest-cov
uv run pytest --cov=your_package \
    --cov-report=term-missing
The report lists lines no test ran. Use it to find what
you forgot.
100% coverage with weak assertions proves
nothing. Never chase the number.

The three that will bite
-> None missing on a test. Strict mypy: Function is missing a return type annotation .

Tests that need your laptop. A test that reads data/expenses.csv passes only on your
