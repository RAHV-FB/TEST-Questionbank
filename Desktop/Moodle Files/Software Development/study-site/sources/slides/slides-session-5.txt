[project.scripts]

===== [slides-session-5.pdf] page 7 =====
typer: the type hints are the specification
@app.command()
def add(merchant: str, amount: float) -> None:
    ...
Usage: expenses add [OPTIONS] MERCHANT AMOUNT
merchant: str with no default → argument. So is amount: float here — a default is
what turns a parameter into an option. --help is generated, never written.

===== [slides-session-5.pdf] page 9 =====
Exit codes
uv run expenses add "Bar Ramon" -5.00
amount must be positive
echo $?
1
0 means success; anything else means failure.
raise typer.Exit(code=1)
Every tool downstream reads that number: the shell, && , CI. A program that prints an
error and exits 0 is a program that lies.

===== [slides-session-5.pdf] page 13 =====
The three that will bite
uv lock after renaming. CI runs uv sync --locked and refuses a lockfile that
disagrees with pyproject.toml .
__main__.py . Still imports app.cli . pytest passes; mypy fails; CI is red.
One command, no @app.callback() . typer drops the command's name, <app> <command> …
errors, your tests fail. The lab gives you the four lines that prevent it.
All three are in the lab's troubleshooting table.
