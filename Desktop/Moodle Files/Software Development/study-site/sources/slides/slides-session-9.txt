===== [slides-session-9.pdf] page 8 =====
One tree, one root
/
├── home/
│   └── alice/              ← your home, ~
│       └── code/
│           └── my-project/
│               ├── .git/
│               ├── src/

Everything is under / . There are no drive letters. On WSL, your Windows disk is at /mnt/c .

ls hides names that start with a dot. .git is one: that is why you never see it, and why it is
safe.
. is the folder you are in. .. is its parent.

Absolute and relative paths
Path
Means
/home/alice/code/expense-tracker
Absolute. Starts at / . Same from anywhere
src/expense_tracker/cli.py
Relative. Starts here
../project-template
Up one level, then down
~/code
Your home, then code
$ cd ~/code/expense-tracker/src
$ cd ../tests
Most "file not found" errors are the wrong current directory. Run pwd first.

Managing files

===== [slides-session-9.pdf] page 14 =====
Make, copy, move, remove
$ mkdir notes
$ touch notes/todo.txt
$ cp notes/todo.txt notes/todo-backup.txt
$ cp -r notes notes-old
$ mv notes/todo-backup.txt notes/old.txt
$ rm notes/old.txt
mv is also rename. cp -r copies a folder and everything in it.
rm does not ask and there is no bin. What it removes is gone.

===== [slides-session-9.pdf] page 15 =====
Dangerous, and how to be careful
$ rm -r notes-old
$ rm -r notes-old/ *
The second line removes notes-old/ and every
file in the current directory.
Habits:
ls the exact path before you rm it. Then press
↑ and swap ls for rm
rm -i asks first. Use it when you are tired
Never rm -rf with a variable you have not
printed

===== [slides-session-9.pdf] page 19 =====
There is no x .
Nobody said this file is a program.
A new file never gets execution permissions.
$ chmod +x hello.sh
$ ls -l hello.sh
-rwxrwxr-x 1 alice alice 31 Oct 11 17:07 hello.sh
$ ./hello.sh
hello

===== [slides-session-9.pdf] page 20 =====
Where chmod does nothing
On WSL, a project under /mnt/c shows every file as rwxrwxrwx , and chmod silently does
nothing.
Keep your projects in your Linux home: ~/code/...
This is the same reason uv and git are faster there
Check: pwd should start with /home/ , not /mnt/
Friday's scripts/check.sh depends on this. In CI it needs the x bit too, and git remembers
it.

Numbers instead of letters

Number
Letters
Typical use

600
rw-------
A private key
777
rwxrwxrwx
Almost never the answer
chmod 777 makes the error go away and the problem worse.
