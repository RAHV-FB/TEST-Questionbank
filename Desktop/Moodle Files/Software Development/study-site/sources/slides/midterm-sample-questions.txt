Mid-term: sample questions
These questions show the kind of question on the mid-term. They are not the exam, and the
exam does not reuse them. The topics are not a full list of what is covered.
The real paper is 1 hour, closed book, pen and paper. It has multiple-choice questions (no
penalty for a wrong answer) and short open questions answered in 5–8 lines. You will not be
asked to write code.
Multiple choice
Q1
You run uv sync in a fresh clone of your group’s repo and see:
$ uv sync
Using CPython 3.13.1
error: Failed to parse `pyproject.toml`
TOML parse error at line 7, column 12
What should you do next?
•
a) Delete .venv and run uv sync again
•
b) Open pyproject.toml at line 7 and look for the syntax mistake
•
c) Run uv sync --upgrade to refresh the packages
•
d) Reinstall uv
Q2
Which of these changes is a refactoring?
•
a) Adding a --month option to the report command
•
b) Fixing a bug where the last expense in the file was skipped
•
c) Renaming variables and splitting one long function into two, with every test still
passing unchanged
•
d) Replacing the CSV file with a JSON file

Q7read code and say what is wrong
def process(rows):
total = 0
for r in rows:
if r[2] == "food":
total += float(r[1])
print("Food total:", total)
return total
1. In one sentence, what does this function do?
2. Name two problems a teammate would face when reading, testing or changing it.
3. Describe (in words, do not write code) how you would change it, and which of the two
problems each change solves.
Q8compare
A teammate shows you this diff from the expense-tracker history:
def load_expenses(path):
with open(path) as file:
rows = list(csv.reader(file))
-
return [Expense(row[0], float(row[1])) for row in rows]
+
expenses = [Expense(row[0], float(row[1])) for row in rows]
+
if any(expense.amount < 0 for expense in expenses):
+
raise ValueError("Negative amount in " + path)
+
return expenses
Two candidate commit messages:
• AFix stuff in loader
• BReject negative amounts when loading expenses
1. What does this change do?
2. Which message is better, and why? Answer from the point of view of someone reading
the history six months later.
3. Name one test you would add for this change, in words.
